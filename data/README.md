# データ辞書

`investiture-1943-09-11.csv` と `investiture-1943-09-11.json` は同じ 10 件を収めています。
CSV は表計算ソフト向け、JSON は出典と凡例を同梱した形です。

## 列の定義

| 列 | 内容 |
| --- | --- |
| `entry_no` | 假記番号。`2603-18` 〜 `2603-27`。原文は `二六〇三一八` のような漢数字表記 |
| `entry_marker` | 原文の番号欄の先頭。最初の一件が `假記`、以降は `同` |
| `rank_ja` | 階級。`海軍大尉` または `海軍中尉` |
| `rank_en` | 同じ階級の英語表記。`Lieutenant` / `Sub-Lieutenant` |
| `rank_source` | **その階級が原文に書かれていたか、繰り返し記号から引き継いだか。** 下記参照 |
| `name_as_printed` | 氏名。原文の字体のまま（`國` `德` など） |
| `surname` / `given_name` | 上を姓と名に分けたもの |
| `subheading_ja` | 直前に置かれた小見出し。該当なしは空欄 |
| `order_class` | 叙勲の等級。全件 `四等` |
| `decoration` | 勲章。全件 `瑞寶章` |

## `rank_source` について

原文の階級欄は、最初の一件に階級を書き、以降は `同` で繰り返します。データでは各行に階級を展開しましたが、
**展開された値と、原文に書かれていた値は、証拠としての強さが違います。**

| 値 | 意味 |
| --- | --- |
| `printed` | その行に階級が書かれている（2603-18 と 2603-26） |
| `ditto` | その行は `同` で、直前の `printed` から引き継いだ |

論文第4節(1) は、大谷（2603-25）の階級を海軍大尉と確定する根拠として、この連鎖を挙げています。
**`rank_source` を残すことで、読者が同じ推論を検証できます。** 展開後の値だけを見せると、
原文に書かれていたかのように見えてしまいます。

## 確かめ方

```
python3 check.py
```

CSV と JSON が同じことを言っているか、假記番号が連番か、`同` の連鎖が破れていないか、
そして**論文第4節(1) の推論をデータの上で辿り直して 2603-25 が海軍大尉に行き着くか**を確かめます。
標準ライブラリのみで動きます。

## 記録していないもの

**読み（振り仮名・ローマ字）** —— 公報に振り仮名がないため、10件のいずれについても記録していません。
`大谷恒` は「オオタニ・ツネ」とも「オオヤ・ヒサシ」とも読めます。論文はこの表記を便宜上のものと断っています。
**推測を列にすると、史料にない情報が史料由来に見えます。**

**所属・乗艦** —— 名簿は階級と氏名のみで、配置を示していません。

**生没年、生前叙勲か死後叙勲か** —— 大谷の行に `故`（故人を示す接頭辞）はありません。論文はこれを
生前叙勲を示唆する材料として挙げつつ、一件だけでは慣行を確定できないとして結論を出していません。

## 字体について

原文の字体を保っています（`國` `德` `鎭` `關`）。新字体には直していません。

一点だけ補正しています。**`小西` の二文字目**は、原文の抽出時に部首の異体字として現れます。
データでは通常の `西` として記録しました。


アジア歴史資料センターの規定する出典表記の形式です。**書き換えずにこの形のまま引いてください。**

`check.py` が三箇所の一致を確かめています。経緯と未確認の箇所は
[リポジトリの README](../README.md#出典) を参照してください。
