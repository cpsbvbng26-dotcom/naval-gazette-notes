# Naval Gazette Notes

種類：史料研究・事例研究　状態：凍結

[![検査](https://github.com/cpsbvbng26-dotcom/naval-gazette-notes/actions/workflows/verify.yml/badge.svg)](https://github.com/cpsbvbng26-dotcom/naval-gazette-notes/actions/workflows/verify.yml)

海軍公報から一件ずつ史料を翻刻し、その史料で確定できることと、できないことを分けて
記録する史料ノートです。

いまのところ 1 件です。1943年9月11日発令の叙勲名簿から、瑞寶章四等の受章者 10 名。

「凍結」は、公開した史料ノートの PDF を指します。正誤表と検査は、これからも足します。

## 史料ノート

**[A Naval Gazette Entry for Lieutenant Otani Tsune（大谷恒）](pdf/naval-gazette-entry-otani-tsune.pdf)**
*A Note on the Investiture List of 11 September 1943 in the Naval Gazette (Internal Circulation Only), Extra Edition*

根本卓哉 — 2026年8月 — プレプリント（査読前）
DOI [10.5281/zenodo.22055709](https://doi.org/10.5281/zenodo.22055709)
Knowledge Commons [レコード](https://works.hcommons.org/records/q36z2-98e12) —— 同じ史料ノートの別の所在。引用は Zenodo の DOI を正とします。
SSRN [10.2139/ssrn.7449338](https://doi.org/10.2139/ssrn.7449338) —— SSRN に登録された同一の本文。

Zenodo の同じ記録には、前の版があります。前の版の題は A Minor Officer in the Imperial Japanese Navy でした。DOI は [10.5281/zenodo.18525532](https://doi.org/10.5281/zenodo.18525532)（2026年2月8日）と [10.5281/zenodo.22055553](https://doi.org/10.5281/zenodo.22055553)（2026年8月22日）です。引くのは現行の 10.5281/zenodo.22055709 です。すべての版に共通する DOI は [10.5281/zenodo.18525531](https://doi.org/10.5281/zenodo.18525531) です。どの版もこの DOI の版であることを、2026年11月11日に DataCite の記録で確かめました。

海軍の下級・中級士官は、自分についての伝記的な記録をほとんど残しません。この階層の人物についての情報は、
散在する公報の記載に頼ることになります。この史料ノートが扱うのは、そのうちの一件です。

**確定できること** —— 発令時の階級は海軍大尉、叙勲は瑞寶章四等、発令日は1943年9月11日、假記番号は 2603-25。

**確定できないこと** —— 名前の読み（大谷はオオタニともオオヤとも、恒はツネともヒサシとも読める）、
所属や乗艦、生没年、そして生前叙勲か死後叙勲か。

この史料からは、いまも確定できません。そのうちいくつかは、史料の外の報道で分かってきました。下の「史料の外にあるもの」に、根拠を分けて書いています。

史料ノートは、確定できないことを**明示的に列挙**します。「オオタニ・ツネ」という表記も、便宜上のものだと断ったうえで使っています。

### 「大尉」と書いてあることの意味

**この史料が確定させるのは、1943年9月11日**時点の階級です。その後の階級については、
この文書は何も言いません。したがって、別の資料や家伝が少佐その他の階級を伝えていても、
それ自体はここでの大尉と矛盾しません。昇進、あるいは死後の特進を、この一件は排除しないからです。

排除もしなければ、裏づけもしません。この名簿から言えるのは発令時点のことだけです。
最終階級を確定するには、別の史料（辞令公報、履歴原表など）が要ります。

なお、大谷の行に `故`（故人を示す接頭辞）はありません。史料ノートはこれを生前叙勲を示唆する材料として
挙げつつ、一件だけでは慣行を確定できないとして結論を出していません。

## 史料の外にあるもの

この公報の外に、報道で分かったことと、家に伝わっていることと、家にあった物があります。どれも一次史料には当たっていません。確かめたことと混ぜないよう、節を分けて書きます。

### 報道と照会で分かったこと

| 事項 | 内容 | 根拠 |
| --- | --- | --- |
| 学歴 | 東京高等商船学校 卒 | 読売新聞 |
| 職歴 | 大阪商船 | 読売新聞 |
| 乗艦 | 愛国丸（特設巡洋艦） | 読売新聞、報道特集（TBS） |
| 職 | 機関長 | 報道特集（TBS） |
| 戦死 | トラック島空襲 | 読売新聞、報道特集（TBS） |
| 最終階級 | 海軍少佐 | 報道特集（TBS） |
| 位階 | 従六位 | 靖國神社への照会 |

公報の大谷恒は、報道の大谷恒（著者の外曾祖父）と同一人物です。氏名・兵科・時期が一致し、JACAR で「大谷恒」を引いて該当するのはこの一件だけです。公報の大尉と報道の少佐の違いは、戦死による一階級の特進によるものと判断しています。

これにより、公報の確定できなかった項目のうち三つが埋まります。

- 所属と乗艦は、愛国丸の機関長です。
- 叙勲は生前です。発令は 1943年9月11日で、戦死はその後です。大谷の行に `故` が無いことと合います。
- 最終階級は少佐です。戦死による一階級の特進を前提にすれば、公報の大尉と矛盾しません。

もう一つ、公報の書き方と照らす点があります。商船学校の卒業生は、海軍の予備員として登録されるのが通例でした。予備員の士官は「海軍予備大尉」のように書かれることがあります。公報の大谷の階級は、2603-18 の `海軍大尉` を `同` で引き継いだもので、`予備` の字はありません。同じ名簿の他の受章者の書き方と比べれば、その理由の手がかりになります。

その人が存命かどうかを、このリポジトリは確かめていません。
存命の家族について書くのは「両親」という語までという決まりを、確かめていない人にも当てました。

### 親族の家にあった勲章と記章

著者の親族の家に、次の勲章と記章がありました。家では「今は無くなった」とされ、いまの所在は分かっていません。

| 勲章・記章 | 数 |
| --- | --- |
| 勲五等瑞宝章 | 2 |
| 勲四等旭日小綬章 | 1 |
| 支那事変従軍記章 | 1 |

名は、伝わっているとおりに書いています。

誰が受けたものかは分かりません。大谷恒のものとも、妻の側の家系のものとも、別の親族のものとも決められません。支那事変従軍記章は陸軍にも海軍にも交付されたので、記章から陸海の別は決まりません。

一つだけ言えることがあります。公報が記録する大谷恒の勲章は瑞寶章四等で、この一覧に入っていません。家にあった物は記録の外にあり、記録された勲章は家にあった物の中に見当たりません。

もう一つあります。勲五等・勲四等のように勲等を冠した名は、2003年の栄典制度の改正より前の呼び方です。伝わっている名が正確なら、どれも改正より前の授与です。戦前か戦後かは、名からは決まりません。

確かめる道は二つあります。叙勲は官報に氏名入りで載ります。受章者の名は、除籍謄本から辿れます。

### 「同」をどう扱ったか

原文の階級欄は、最初の一件に `海軍大尉` と書き、以降は `同` で繰り返します。データでは階級を各行に展開し、
**それが書かれていたものか、繰り返しから引き継いだものかを `rank_source` 列で区別**しています。

```
2603-18  printed  海軍大尉   ← 書かれている
2603-19  ditto    海軍大尉   ← 同 から引き継いだ
```

史料ノートが大谷の階級を大尉と断定できる根拠は、まさにこの連鎖です（2603-18 に `海軍大尉` とあり、
間の各行がすべて `同` なので、2603-25 まで引き継がれる）。根拠を列として残すことで、
読者が同じ推論を辿り直せます。

### データを確かめる

```

```

`data/check.py` 自身は、標準ライブラリだけで書いています。GitHub Actions が push ごとに実行しています。
57 項目を確かめます —— CSV と JSON が全列で一致すること、
假記番号が 2603-18 から欠けなく並ぶこと、`同` の連鎖が破れていないこと（引き継ぐ元のない `ditto` は

## 出典

この一文が、このリポジトリの正式な出典表記です。以下すべての場所で同一の文字列を用いています。

```
JACAR（アジア歴史資料センター）Ref.C12070491000、海軍公報（部内限）號外　昭和十八年九月十一日發令（防衛省防衛研究所）
```

レコードの恒久リンク: <https://www.jacar.archives.go.jp/das/meta/C12070491000>

アジア歴史資料センターは、資料を引くときの引用例を推奨しています —— レファレンスコードは `Ref.` を冠した11桁、
原資料の所在は**簿冊名まで**を書き、所蔵機関名をかっこに入れる、二回目以降は `JACAR` と Ref. を略記してよい。
上の一文はこの形に合わせたものです。このリポジトリのデータを再利用する場合も、
自己流に書き換えず、この形のまま引きます。

> 未確認が一点ある。 上の表記には簿冊名と整理番号が入っていない。
> 規定は簿冊レベルまでの記載を求めているが、JACAR の書誌からまだ確認できていない
> （この作業環境からは jacar.go.jp / jacar.archives.go.jp に接続できない）。
> 確認でき次第、件名と所蔵機関名のあいだに補う。

上の囲みは、2026-11-12 より前の記録です。
2026-11-12 の法令の点検で、Sophaxis の取り寄せの仕事（GitHub Actions）が、JACAR の目録の頁と「資料画像の利用について」の頁を取り寄せました。
JACAR の頁は、引用例を「推奨します」と書いています。
規定として求めているのではありません。
上の段落の「形式を定めています」「規定は」は、この点で強すぎたので改めました。
目録の簿冊名・件名・請求番号は、典拠の表に書き足しました。
目録は資料作成年月日を「昭和１９年～昭和１９年」と表示しています。
発令の日付（昭和十八年九月十一日）と、号外の出た年は、同じとは限りません。
五か所の出典表記の一文は、この点検では変えていません。
2026-11-12 に Claude が決めました。
引用例は推奨であり、表記は凍結した史料ノートの紙面と同じ書き方を保っているからです。

確かめる手順は、公開の課題 [#26](https://github.com/cpsbvbng26-dotcom/naval-gazette-notes/issues/26) に書いています。

翻刻は、JACAR が公開する画像を目視で確認したものです。印刷の状態により複数の読みが成り立つ場合は、
その旨が史料ノート本文に示されています。

### 一箇所で決めて、機械で揃えている

同じ出典を README・[`data/README.md`](data/README.md)・JSON・`CITATION.cff`・[`data/datapackage.json`](data/datapackage.json) の 5 箇所に書くと、一つだけ直したときに食い違います。
そうならないよう、[`data/check.py`](data/check.py) が 5 箇所の文字列が一字一句同じであることを確かめます。
ずれた時点で検査が落ちます。

## 原資料の画像は入っていない

このリポジトリにあるのは、テキストの翻刻と、著者自身の史料ノート PDF だけです。
`pdf/` の 1 ファイルは wkhtmltopdf で組んだ全2ページの自作 PDF で、**埋め込み画像は 0 件**です。
JACAR が公開する原資料のスキャン画像は、どこにも含めていません。

これは意識して引いた線です。JACAR の案内では、**防衛省防衛研究所提供資料の資料画像**を
出版物や番組に用いる場合、所蔵機関への照会が求められます。翻刻テキストと自作の史料ノートは
それに当たらないが、画像を入れた時点で話が変わります。

> 今後の運用。 このリポジトリに原資料のスキャン画像を加える場合は、
> その前に防衛省防衛研究所 戦史研究センターに確認すること。
> 忘れないよう、[`data/check.py`](data/check.py) が画像ファイルの混入と、
> PDF への画像埋め込みを検査する。入った時点で検査が落ちる。

著作権法上の評価をここで下すつもりはありません。運用上の線だけを引いて、機械で守っています。

新たな読み取りは加えていません。`rank_source` 列による「同」の解決は、史料ノート第4節(1) の論証を
