# Naval Gazette Notes

海軍公報から一件ずつ史料を翻刻し、**その史料で確定できることと、できないことを分けて記録する**リポジトリです。

いまのところ一件です。1943年9月11日発令の叙勲名簿から、瑞寶章四等の受章者10名。

## 論文

**[A Naval Gazette Entry for Lieutenant Otani Tsune（大谷恒）](pdf/naval-gazette-entry-otani-tsune.pdf)**
*A Note on the Investiture List of 11 September 1943 in the Naval Gazette (Internal Circulation Only), Extra Edition*

根本卓哉 — 2026年8月 — プレプリント（査読前）
DOI [10.5281/zenodo.22055709](https://doi.org/10.5281/zenodo.22055709)

海軍の下級・中級士官は、自分についての伝記的な記録をほとんど残しません。この階層の人物についての情報は、
散在する公報の記載に頼ることになります。この論文が扱うのは、そのうちの一件です。

**確定できること** —— 発令時の階級は海軍大尉、叙勲は瑞寶章四等、発令日は1943年9月11日、假記番号は 2603-25。

**確定できないこと** —— 名前の読み（大谷はオオタニともオオヤとも、恒はツネともヒサシとも読めます）、
所属や乗艦、生没年、そして生前叙勲か死後叙勲か。

論文は後者を**明示的に列挙**します。「オオタニ・ツネ」という表記も、便宜上のものだと断ったうえで使っています。

## データ

論文の第3節にある翻刻を、そのまま機械可読な形にしたものです。

| | |
| --- | --- |
| [`data/investiture-1943-09-11.csv`](data/investiture-1943-09-11.csv) | 10件。表計算ソフトでそのまま開けます |
| [`data/investiture-1943-09-11.json`](data/investiture-1943-09-11.json) | 同じ内容に、出典と凡例を付けたもの |
| [`data/README.md`](data/README.md) | 各列の定義と、記録しなかったもの |
| [`data/check.py`](data/check.py) | 二つのファイルの整合と、階級の連鎖を確かめる |

**なぜデータにするのか。** 論文の第7節は、次の一手として「同じ発令の他の受章者を比較し、名簿の編成原理を
再構成すること」を挙げています。**それには翻刻が表になっている必要があります。** PDF の中にあるままでは、
誰も着手できません。

### 「同」をどう扱ったか

原文の階級欄は、最初の一件に `海軍大尉` と書き、以降は `同` で繰り返します。データでは階級を各行に展開し、
**それが書かれていたものか、繰り返しから引き継いだものかを `rank_source` 列で区別**しています。

```
2603-18  printed  海軍大尉   ← 書かれている
2603-19  ditto    海軍大尉   ← 同 から引き継いだ
```

論文が大谷の階級を大尉と断定できる根拠は、まさにこの連鎖です（2603-18 に `海軍大尉` とあり、
間の各行がすべて `同` なので、2603-25 まで引き継がれる）。**根拠を列として残すことで、
読者が同じ推論を辿り直せます。**

### データを確かめる

```
python3 data/check.py
```

標準ライブラリだけで動きます。19 項目を確かめます —— CSV と JSON が全列で一致すること、
假記番号が 2603-18 から欠けなく並ぶこと、`同` の連鎖が破れていないこと（引き継ぐ元のない `ditto` は
翻刻の取りこぼしを意味します）、**論文第4節(1) の推論をデータの上で実際に辿り直し、
2603-25 の階級が海軍大尉に行き着くこと**、そして**出典表記が四箇所で一字一句同じであること**。

## 出典

**この一文が、このリポジトリの正式な出典表記です。** 以下すべての場所で同一の文字列を用いています。

```
JACAR（アジア歴史資料センター）Ref.C12070491000、海軍公報（部内限）號外　昭和十八年九月十一日發令（防衛省防衛研究所）
```

レコードの恒久リンク: <https://www.jacar.archives.go.jp/das/meta/C12070491000>

アジア歴史資料センターは出典表記の形式を定めています —— レファレンスコードは `Ref.` を冠した11桁、
原資料の所在は**簿冊レベルまでの資料名と所蔵機関名**を添える、二回目以降は `JACAR` と Ref. を略記してよい。
上の一文はこの形式に合わせたものです。**このリポジトリのデータを再利用する場合も、
自己流に書き換えず、この形のまま引いてください。**

> **未確認が一点あります。** 上の表記には**簿冊名と整理番号が入っていません。**
> 規定は簿冊レベルまでの記載を求めていますが、JACAR の書誌からまだ確認できていません
> （この作業環境からは jacar.go.jp / jacar.archives.go.jp に接続できません）。
> 確認でき次第、件名と所蔵機関名のあいだに補います。

翻刻は、JACAR が公開する画像を目視で確認したものです。印刷の状態により複数の読みが成り立つ場合は、
その旨が論文本文に示されています。

### 一箇所で決めて、機械で揃えている

同じ出典を README・JSON・`CITATION.cff` の三箇所に書くと、片方だけ直したときに食い違います。
そうならないよう、[`data/check.py`](data/check.py) が**三箇所の文字列が一字一句同じであることを確かめます。**
ずれた時点で検査が落ちます。

## 収録していないもの

**同じ公報にあるが、翻刻していない部分があります。**

- **敍勲三等授瑞寶章**（假記 2603-13 〜 2603-17、5名）。論文は五名の受章者がいることを記録していますが、
  氏名は翻刻していません
- 同じ画像の罫線の下から始まる **2603-30 以降の一群**。これは別項目にあたるため、論文は扱っていません

**読みは一切記録していません。** 公報に振り仮名がないためです。推測で補うと、
史料にない情報を史料から出たもののように見せることになります。
